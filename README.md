# 🍜 Wok & Roll — Campus Food Ordering System

A modern **campus food ordering web app** designed to eliminate long queues during recess by enabling students to **pre-order food** while allowing kitchen staff to **manage orders in real time**.

---

## 🚀 Features

### 👤 Student Side

* 🍜 Browse today's menu
* ➕ Add items to cart
* 🔢 Increase/decrease quantity
* 🧾 View order summary
* ⏱️ See preparation time

### 🍳 Kitchen/Admin Side *(Upcoming)*

* 📋 Live order dashboard
* 🔄 Update order status (Cooking → Ready)
* 📊 Order queue management

## ⚡ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/wok-and-roll.git
cd wok-and-roll
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the development server

```bash
npm run dev
```

---

## 🧠 How It Works

* `MenuPage` displays all food items
* Each item is rendered using `MenuCard`
* Cart state is managed locally (for now)
* Future updates will integrate backend APIs
